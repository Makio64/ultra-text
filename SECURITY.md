# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please do not open a public issue for security reports. Instead, report privately through
[GitHub security advisories](https://github.com/Makio64/ultra-text/security/advisories/new).

You can expect an acknowledgement within a week. Once a fix is available it will be released
as a patch version and credited to you unless you prefer otherwise.
